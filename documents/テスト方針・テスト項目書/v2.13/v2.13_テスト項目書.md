## 2. 重点確認ポイント

v2.13 は **売切同期が参加者注文を止められること**、**限定食数を超えられないこと**、**自己負担のある事前決済にシステム利用料 110 円が乗ること** が最重要。次に注文なし参加の集計除外、オプションの確定単価、フォーム未回答での確定拒否。

1. partner の売切切替が、注文受付中イベントへ **10 秒以内**に反映される（Trigger + index）
2. 売切・完売メニューは UI 無効化だけでなく、`addToCart` / 注文確定 / Checkout でも拒否される
3. 残数は `ordered` のみ。カート投入は在庫を確保しない（他参加者に先取りされうる。仕様どおり）
4. 要認証ガードの着地は `/register`。ヘッダーの「ログイン」だけ `/login`（#2373）
5. 公開イベント URL の JS レンダリング後に `noindex` が付かない（#2301 / #2335）
6. SendGrid テンプレの「3日 / 72時間」が残っていると、コードは 48h なのにメール文言が古い
7. 事前決済で自己負担が 1 円以上なら **1 Checkout につき税込 110 円**。当日払いと自己負担 0 円は 0 円。導入前の注文履歴に後付けしない
8. 「食事は持参」は ¥0 で参加でき、店舗の注文・請求書には出ない。参加者一覧と定員には入る
9. 必須オプション未選択はカートに入らない。確定後の単価と項目名が注文に残る
10. フォームを付けたイベントは、必須未回答のまま注文を確定できない
