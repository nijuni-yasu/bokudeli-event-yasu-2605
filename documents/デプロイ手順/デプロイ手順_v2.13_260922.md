## トラブルシュート

### `Deploy functions` が failure policy で abort する

**症状**: `Pass the --force option to deploy functions with a failure policy`。

**原因**: `onPartnerMenuSoldOutChanged` が本番初出（`retry: true`）。

**対処**: B-5 のあと `Deploy functions` を re-run。以降は再発しない。CI は #2356 で名前指定 `--force` する想定。

### `Deploy functions` が `Command aborted` で失敗する

**症状**: `The following functions are found in your project but do not exist in your local source` に続いて `Command aborted.`。

**原因**: `--force` 廃止後、`index.ts` に export の無い関数が GCP 上に残っていると CLI が削除確認を求め、非対話の Actions では abort する。

**対処**: A-3 の手順で残存関数を削除して再実行する。

### 売切が参加者に反映されない

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| ずっと変わらない | Trigger 未デプロイ | `functions:list` で存在確認 |
| failed-precondition | index building | Enabled まで待つ |
| 下書き/申請中だけ変わらない | 仕様 | 承認時スナップショットで反映 |

### 残数が出ない / 定数クエリエラー

**原因**: `member_orders` の `event_id + menu_id + status` index が building。

**対処**: Enabled 待ち。注文確定のサーバー判定も同じ index を使う。

### `Deploy user` が communitylist rewrite で 400

**原因**: `handleCommunityListSeoRequest` 未デプロイのまま Hosting が先。

**対処**: functions 完了後に `Deploy user` を re-run（v2.12 の sitemap と同じ）。

### 予約メールの期限が 3 日のまま

**原因**: SendGrid テンプレ未更新。

**対処**: B-2。コードロールバックでは直らない。

### PF プロフィールから注文が消える

v2.13 では `0046` を再実行しない。もし消えたら **v2.12 の `enterprise_id: null` 欠落**を疑う（コードロールバックだけでは直らない）。

### CLI の注意

| コマンド | 注意 |
| --- | --- |
| `firebase functions:list` | **`--region` オプションは使えない**（unknown option エラー） |
